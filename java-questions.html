What do you mean by platform independence? Write down the steps to compile and execute java program with necessary diagram. / What is the "Write Once Run Anywhere" feature of Java? Explain with JVM architecture.
Model Answer

Platform Independence in Java

Platform independence means a Java program, once written and compiled, can run on any operating system or hardware without modification. This is Java's most famous feature, described by Sun Microsystems as "Write Once, Run Anywhere" (WORA).

Traditional languages like C/C++ compile source code directly into machine code specific to an OS (Windows, Linux, Mac). Java works differently — it compiles into an intermediate format called Bytecode, which is platform-neutral. Each OS has a JVM (Java Virtual Machine) that reads and executes this bytecode. So the same bytecode runs on any OS that has a JVM installed.

Key Components

  • JDK (Java Development Kit): The complete development environment. Contains tools to write, compile, and run Java programs. Includes the compiler (javac), JRE, and developer tools.
  • JRE (Java Runtime Environment): Contains the JVM and libraries needed to run Java programs. Used by end-users who only want to run programs, not develop them.
  • JVM (Java Virtual Machine): An abstract machine that reads Java bytecode and translates it into machine code for the underlying hardware. Each OS has its own JVM.
  • Bytecode: The intermediate, platform-neutral code produced by the Java compiler (.class file).

Steps to Compile and Execute a Java Program

/* Step 1: Write the source code in a text editor */
/* File: HelloWorld.java  (filename must match class name) */

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Pokhara University!");
    }
}
/* Step 2: Compile using javac command */
javac HelloWorld.java
/* This creates HelloWorld.class (bytecode file) */

/* Step 3: Run using java command */
java HelloWorld
/* Output: Hello, Pokhara University! */

Diagram: Java Execution Process

Source Code (.java)
       ↓  javac (Java Compiler)
   Bytecode (.class)
       ↓
  ┌─────────────────────────────────────────┐
  │            JVM (Platform-Specific)      │
  │   ┌──────────┐  ┌────────────────────┐  │
  │   │  Class   │  │  Execution Engine  │  │
  │   │  Loader  │→ │  (Interprets +     │  │
  │   └──────────┘  │   JIT Compiler)    │  │
  │                 └────────────────────┘  │
  └─────────────────────────────────────────┘
       ↓
  Machine Code runs on OS (Windows/Linux/Mac)

The JVM on Windows produces Windows machine code. The JVM on Linux produces Linux machine code. But both read the same .class bytecode. This is why Java is platform-independent.

Structure of a Java Program

A Java program has a well-defined structure. Every Java program must have at least one class, and execution begins from the main() method.

// 1. Package declaration (optional)
package mypackage;

// 2. Import statements (optional)
import java.util.Scanner;

// 3. Class declaration (mandatory)
public class MyProgram {

    // 4. Instance variables (fields)
    private String name;
    private int age;

    // 5. main() method — entry point of program
    public static void main(String[] args) {
        System.out.println("Java Program Structure!");
    }
}

Four Core OOP Concepts with Real-World Examples

1. Encapsulation — Wrapping data (variables) and methods together inside a class, and hiding internal details from the outside world using access modifiers (private, public).

Real-world example: A car's engine is hidden under the hood (private). You interact with it only through the steering wheel and pedals (public methods). You don't need to know how the engine works internally.

class BankAccount {
    private double balance;          // hidden from outside
    public void deposit(double amt) { balance += amt; }
    public double getBalance()       { return balance; }
}

2. Inheritance — A child class (subclass) inherits properties and methods from a parent class (superclass) using the extends keyword. Promotes code reuse.

Real-world example: "Vehicle" is a parent class. "Car" and "Bike" are child classes. They inherit common features (wheels, speed) but add their own (Car has 4 doors, Bike has 2 wheels).

class Animal    { void eat() { System.out.println("Eating..."); } }
class Dog extends Animal { void bark(){ System.out.println("Woof!"); } }

3. Polymorphism — One method name behaves differently depending on the object or arguments. Achieved through method overloading (compile-time) and method overriding (runtime).

Real-world example: A "print" button on a printer — it prints documents, photos, or PDFs differently based on the file type, but the button (method call) is the same.

4. Abstraction — Hiding complex implementation details and showing only the necessary interface to the user. Achieved using abstract classes and interfaces.

Real-world example: When you press the "Start" button on a car, you don't need to know about fuel injection, engine timing, etc. The complexity is hidden; you just see the result.

Model Answer

What is an Array?

An array is a container object that holds a fixed number of values of the same data type. Each element in an array is accessed by its index number, starting from 0. Arrays are stored in contiguous memory locations.

1D Array (One-Dimensional Array)

A single row of elements. Think of it like a list or a single column in a table.

public class OneDArray {
    public static void main(String[] args) {

        // Declaration and initialization of 1D array
        int[] marks = {85, 90, 75, 92, 68};

        // Accessing individual elements
        System.out.println("First element: " + marks[0]); // 85
        System.out.println("Third element: " + marks[2]); // 75

        // Displaying all elements using for loop
        System.out.println("All Marks:");
        for (int i = 0; i < marks.length; i++) {
            System.out.println("marks[" + i + "] = " + marks[i]);
        }
        // Output: marks[0]=85, marks[1]=90, marks[2]=75, ...
    }
}

2D Array (Two-Dimensional Array)

An array of arrays — like a table with rows and columns (a matrix). Accessed using two indices: [row][column].

public class TwoDArray {
    public static void main(String[] args) {

        // 2D array: 3 rows, 3 columns (3x3 matrix)
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        // Accessing a specific element
        System.out.println("Row 0, Col 1: " + matrix[0][1]); // 2
        System.out.println("Row 2, Col 2: " + matrix[2][2]); // 9

        // Displaying all elements using nested for loop
        System.out.println("Matrix:");
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[i].length; j++) {
                System.out.print(matrix[i][j] + " ");
            }
            System.out.println();
        }
        /* Output:
           1 2 3
           4 5 6
           7 8 9  */
    }
}
Exam Tip: Always mention index starts from 0. Show array.length for 1D, and matrix.length + matrix[i].length for 2D. Nested for loop is essential for 2D display.
HIGH 8 Marks 2025 Explain Java Strings and StringBuffer with examples. How does StringBuffer differ from String? ▼
Explain Java Strings and StringBuffer with examples. How does StringBuffer differ from String?
Model Answer

Java String

A String in Java is a sequence of characters. Strings are objects of the java.lang.String class. The most important property of String in Java is that it is immutable — once a String object is created, its value cannot be changed. Any modification creates a new String object in memory.

public class StringDemo {
    public static void main(String[] args) {

        String s1 = "Hello";
        String s2 = "World";

        // String methods
        System.out.println(s1.length());        // 5
        System.out.println(s1.toUpperCase());   // HELLO
        System.out.println(s1.charAt(0));       // H
        System.out.println(s1.concat(" World")); // Hello World
        System.out.println(s1.equals(s2));      // false
        System.out.println(s1.substring(1, 4)); // ell

        // Immutability demo
        String s3 = s1 + " Java";  // creates NEW object, s1 unchanged
    }
}

StringBuffer

A StringBuffer is a mutable sequence of characters. Unlike String, its content can be changed without creating new objects. It is used when a string needs to be modified many times (e.g., in loops). StringBuffer is also thread-safe (synchronized).

public class StringBufferDemo {
    public static void main(String[] args) {

        StringBuffer sb = new StringBuffer("Hello");

        sb.append(" World");   // modifies SAME object → "Hello World"
        sb.insert(5, ",");      // → "Hello, World"
        sb.reverse();           // → "dlroW ,olleH"
        sb.delete(0, 5);        // removes chars 0-4
        sb.replace(0, 3, "Hi"); // replaces range with "Hi"

        System.out.println(sb.toString()); // convert back to String
        System.out.println(sb.length());
    }
}

String vs StringBuffer — Key Differences

Feature        | String              | StringBuffer
---------------|---------------------|----------------------
Mutability     | Immutable           | Mutable
Memory         | Creates new object  | Modifies same object
               | on each change      |
Performance    | Slow (for many      | Fast (no new objects)
               | modifications)      |
Thread Safety  | Yes (immutable)     | Yes (synchronized)
Use Case       | Fixed strings       | Frequently modified
When to use    | s = "abc"           | Loops, building text
Exam Tip: The key difference to always mention: String is immutable, StringBuffer is mutable. Always show StringBuffer.append(), insert(), reverse(), delete() methods. Immutability means every change to String creates a new object — this wastes memory.

Model Answer

What are Wrapper Classes?

In Java, there are 8 primitive data types (int, double, char, boolean, etc.) that are not objects. However, Java's Collection Framework (like ArrayList) can only store objects, not primitives. Wrapper classes provide a way to use primitive data types as objects. Each primitive type has a corresponding wrapper class in java.lang package.

Primitive Type  | Wrapper Class
----------------|---------------
byte            | Byte
short           | Short
int             | Integer
long            | Long
float           | Float
double          | Double
char            | Character
boolean         | Boolean

Wrapper classes also provide useful utility methods for conversion, parsing, and comparison.

Integer num = Integer.valueOf(25);        // int to Integer object
int x = num.intValue();                    // Integer to int
int y = Integer.parseInt("100");         // String to int
String s = Integer.toString(50);          // int to String
int max = Integer.MAX_VALUE;              // 2147483647

Autoboxing

Autoboxing is the automatic conversion of a primitive type to its corresponding wrapper class object. Java does this automatically — the programmer does not need to manually call valueOf() or a constructor.

// WITHOUT autoboxing (old way)
Integer obj1 = Integer.valueOf(10);

// WITH autoboxing (Java 5+) — automatic conversion
Integer obj2 = 42;  // int 42 is automatically boxed to Integer

// Autoboxing in Collections
java.util.ArrayList<Integer> list = new java.util.ArrayList<>();
list.add(10);  // int 10 is autoboxed to Integer automatically
list.add(20);

Unboxing

Unboxing is the reverse — the automatic conversion of a wrapper class object back to its corresponding primitive type.

Integer wrapped = 100;      // autoboxing: int → Integer
int primitive = wrapped;    // unboxing: Integer → int (automatic)

// Full demonstration
Integer a = 5;             // autoboxing
Integer b = 10;            // autoboxing
int sum = a + b;           // unboxing: a and b converted to int for + operator
System.out.println("Sum = " + sum); // Sum = 15

Why Autoboxing/Unboxing is Important

  • Makes code cleaner and shorter — no need for explicit conversion calls.
  • Allows primitives to be used seamlessly in Collections (ArrayList, HashMap, etc.).
  • Reduces programmer errors from manual boxing/unboxing.
Note: Autoboxing can cause performance issues in tight loops because many wrapper objects are created. Also, comparing Integer objects with == compares references (not values) — always use .equals() for comparison.

HIGH 7 Marks 2025 · 2024 Fall Define class. Create Employee class with default and parameterized constructors. Write main() and create two objects. ▼
Define class. Create a class Employee having two constructors to set default and parameterized value to name, designation and salary instance variables, and displayInfo() method. Also write main method inside same class and create two objects for both constructors, finally call displayInfo() to show result.
Model Answer

What is a Class?

A class is a blueprint or template for creating objects. It defines the properties (instance variables/fields) and behaviors (methods) that objects of the class will have. A class is not a real object itself — it describes what objects of that type will look like.

What is a Constructor?

A constructor is a special method in a class that is automatically called when an object is created using the new keyword. It has the same name as the class and no return type. Constructors are used to initialize instance variables. There are two types: Default Constructor (no parameters) and Parameterized Constructor (with parameters).

public class Employee {

    // Instance variables (fields)
    private String name;
    private String designation;
    private double salary;

    // Default Constructor — sets default values
    public Employee() {
        name        = "Unknown";
        designation = "Not Assigned";
        salary      = 0.0;
    }

    // Parameterized Constructor — sets values passed by user
    public Employee(String n, String d, double s) {
        name        = n;
        designation = d;
        salary      = s;
    }

    // Method to display employee information
    public void displayInfo() {
        System.out.println("--- Employee Info ---");
        System.out.println("Name        : " + name);
        System.out.println("Designation : " + designation);
        System.out.println("Salary      : " + salary);
    }

    // Main method — entry point
    public static void main(String[] args) {

        // Object 1: using Default Constructor
        Employee emp1 = new Employee();
        emp1.displayInfo();

        // Object 2: using Parameterized Constructor
        Employee emp2 = new Employee("Ram Sharma", "Software Engineer", 75000.00);
        emp2.displayInfo();
    }
}

/* Output:
--- Employee Info ---
Name        : Unknown
Designation : Not Assigned
Salary      : 0.0
--- Employee Info ---
Name        : Ram Sharma
Designation : Software Engineer
Salary      : 75000.0  */

Compare Method Overriding and Method Overloading with an example program.
Model Answer

Method Overloading (Compile-Time Polymorphism)

Method overloading is when two or more methods in the same class have the same name but different parameters (different number, type, or order of parameters). Java decides which method to call at compile time based on the arguments provided. It is also called static polymorphism.

class Calculator {

    // Same method name 'add' with different parameters
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {  // different data type
        return a + b;
    }

    int add(int a, int b, int c) {    // different number of params
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(5, 3));          // 8
        System.out.println(c.add(2.5, 3.5));      // 6.0
        System.out.println(c.add(1, 2, 3));       // 6
    }
}

Method Overriding (Runtime Polymorphism)

Method overriding is when a child class provides its own implementation for a method that is already defined in its parent class. The method must have the same name, same return type, and same parameters. Java decides which version to call at runtime based on the object type. It is also called dynamic polymorphism.

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {  // overrides parent method
        System.out.println("Dog barks: Woof!");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("Cat meows: Meow!");
    }
}

class Main {
    public static void main(String[] args) {
        Animal a1 = new Dog();  // parent ref, child object
        Animal a2 = new Cat();
        a1.sound(); // Dog barks: Woof!
        a2.sound(); // Cat meows: Meow!
    }
}
Overloading vs Overriding:
Feature          | Overloading           | Overriding
-----------------|-----------------------|------------------
Where            | Same class            | Parent + Child class
Parameters       | Must be different     | Must be same
Return type      | Can differ            | Must be same
Polymorphism     | Compile-time (static) | Runtime (dynamic)
Keyword needed   | None                  | @Override (recommended)
Inheritance      | Not required          | Required

HIGH 8 Marks Every Year 2022–2025 Define Inheritance. Does Java support multiple inheritance? Justify with code example. ▼
Define Inheritance. Does java support multiple inheritance? If yes justify with code example. / How do you create multiple inheritance in java? Explain with code example.
Model Answer

What is Inheritance?

Inheritance is one of the four pillars of OOP. It allows a child class (subclass) to acquire the properties and behaviors (methods and fields) of a parent class (superclass) using the extends keyword. Inheritance promotes code reusability and establishes an "IS-A" relationship between classes. For example, "Dog IS-A Animal."

Types of Inheritance in Java

  • Single Inheritance: One child class inherits from one parent class.
  • Multilevel Inheritance: A chain — A extends B, B extends C.
  • Hierarchical Inheritance: Multiple child classes inherit from one parent.
  • Multiple Inheritance (via Interface): One class implements multiple interfaces.

Does Java Support Multiple Inheritance?

Java does NOT support multiple inheritance through classes (a class cannot extend two classes simultaneously). This is because it would cause the "Diamond Problem" — ambiguity about which parent's version of a method to use when two parents have the same method.

However, Java supports multiple inheritance through interfaces. A class can implement multiple interfaces, effectively achieving multiple inheritance without the diamond problem.

// Interface 1
interface Printable {
    void print();
}

// Interface 2
interface Showable {
    void show();
}

// Multiple inheritance: implements TWO interfaces
class Document implements Printable, Showable {

    @Override
    public void print() {
        System.out.println("Printing the document...");
    }

    @Override
    public void show() {
        System.out.println("Showing the document...");
    }

    public static void main(String[] args) {
        Document doc = new Document();
        doc.print();  // Printing the document...
        doc.show();   // Showing the document...
    }
}

Multilevel Inheritance Example

class Vehicle   { void move()  { System.out.println("Vehicle moves"); } }
class Car extends Vehicle { void drive() { System.out.println("Car drives"); } }
class Sedan extends Car  { void park()  { System.out.println("Sedan parks"); } }

// Sedan inherits from Car AND Vehicle (multilevel)
Sedan s = new Sedan();
s.move(); s.drive(); s.park();
Exam Tip: Always explicitly state "Java does NOT support multiple inheritance through classes due to the Diamond Problem, but achieves it through interfaces." This distinction earns key marks every year.
HIGH 7 Marks 2025 · 2024 Write a Java program to create an interface Shape with calculateArea(). Implement in Circle and Rectangle classes. ▼
Write a java program to create an interface Shape with a method calculateArea(). Implement this interface in two classes: Circle and Rectangle. Display the area of each shape.
Model Answer

What is an Interface?

An interface in Java is a completely abstract class — it contains only method declarations (no method body) and constants. It defines what a class must do, but not how to do it. A class uses the implements keyword to implement an interface and must provide implementations for all methods. Interfaces enable abstraction and multiple inheritance in Java.

// Step 1: Define the interface
interface Shape {
    double calculateArea();  // method declaration (no body)
}

// Step 2: Implement interface in Circle class
class Circle implements Shape {
    private double radius;

    public Circle(double r) {
        radius = r;
    }

    @Override
    public double calculateArea() {
        return Math.PI * radius * radius;  // π × r²
    }
}

// Step 3: Implement interface in Rectangle class
class Rectangle implements Shape {
    private double length, width;

    public Rectangle(double l, double w) {
        length = l;
        width  = w;
    }

    @Override
    public double calculateArea() {
        return length * width;             // l × w
    }
}

// Step 4: Test all shapes
public class ShapeDemo {
    public static void main(String[] args) {

        Shape circle    = new Circle(7.0);
        Shape rectangle = new Rectangle(5.0, 4.0);

        System.out.printf("Area of Circle    : %.2f%n", circle.calculateArea());
        System.out.printf("Area of Rectangle : %.2f%n", rectangle.calculateArea());
    }
}
/* Output:
Area of Circle    : 153.94
Area of Rectangle : 20.00  */

HIGH 7 Marks 2025 (OR option) Write a Java program with abstract class Motor. Inherit in Car and Bus with start_engine(), stop_engine() methods. ▼
Write a java program with an abstract class Motor. Inherits this class from two other classes Car and Bus using the methods start_engine(), stop_engine() and display_engine() in both the classes.

What is an Abstract Class?

An abstract class is a class that cannot be instantiated (you cannot create an object of it directly). It is declared using the abstract keyword. It can have both abstract methods (no body — child must implement) and concrete methods (with body). Abstract classes define a common template for all subclasses.

Difference — Abstract Class vs Interface: An abstract class can have instance variables, constructors, and concrete methods. An interface (traditional) can only have method signatures and constants.

// Abstract class — cannot be instantiated
abstract class Motor {

    // Abstract methods — subclasses MUST implement these
    abstract void start_engine();
    abstract void stop_engine();
    abstract void display_engine();
}

// Car class inherits Motor and provides implementations
class Car extends Motor {

    @Override
    void start_engine() {
        System.out.println("Car engine started - Vroom!");
    }

    @Override
    void stop_engine() {
        System.out.println("Car engine stopped.");
    }

    @Override
    void display_engine() {
        System.out.println("Car: 2000cc 4-cylinder petrol engine");
    }
}

// Bus class inherits Motor and provides its own implementations
class Bus extends Motor {

    @Override
    void start_engine() {
        System.out.println("Bus engine started - Rumble!");
    }

    @Override
    void stop_engine() {
        System.out.println("Bus engine stopped.");
    }

    @Override
    void display_engine() {
        System.out.println("Bus: 5000cc V8 diesel engine");
    }
}

public class MotorDemo {
    public static void main(String[] args) {

        Car car = new Car();
        car.start_engine();
        car.display_engine();
        car.stop_engine();

        System.out.println("---");

        Bus bus = new Bus();
        bus.start_engine();
        bus.display_engine();
        bus.stop_engine();
    }
}
/* Output:
Car engine started - Vroom!
Car: 2000cc 4-cylinder petrol engine
Car engine stopped.
---
Bus engine started - Rumble!
Bus: 5000cc V8 diesel engine
Bus engine stopped.  */

Model Answer

What is a Package?

A package in Java is a namespace that organizes a set of related classes and interfaces. It is like a folder for Java files. Packages prevent naming conflicts, provide access control, and make code easier to locate and manage. Java has built-in packages (java.lang, java.util, java.io) and you can create your own user-defined packages.

Uses of Package

  • Organizes code into logical groups (e.g., all database classes in a "db" package).

Model Answer

Why Do We Need Multithreading?

Multithreading is the ability of a program to execute two or more parts (threads) simultaneously. A thread is a lightweight, independent unit of execution within a program.

Without multithreading, a program executes tasks one after another (sequentially). If one task is slow (like downloading a file), the whole program freezes and waits. With multithreading, multiple tasks run concurrently, making programs faster and more responsive.

Real-world uses: Web servers handle many requests simultaneously. Media players play audio while decoding video. Games update graphics while processing input — all at once.

Method 1: Creating a Thread by Extending Thread Class

Create a class that extends java.lang.Thread and override the run() method. Start the thread with .start().

class MyThread extends Thread {
    private String threadName;

    public MyThread(String name) {
        threadName = name;
    }

    @Override
    public void run() {  // contains task to execute
        for (int i = 1; i <= 3; i++) {
            System.out.println(threadName + ": Count = " + i);
            try { Thread.sleep(200); } // pause 200ms
            catch (InterruptedException e) { e.printStackTrace(); }
        }
    }
}

Method 2: Creating a Thread by Implementing Runnable Interface

Create a class that implements java.lang.Runnable and override run(). Pass the object to a Thread constructor. This is the preferred approach because Java supports only single class inheritance — if your class already extends another class, you cannot extend Thread. Runnable solves this problem.

class RunnableTask implements Runnable {
    private String taskName;

    public RunnableTask(String name) {
        taskName = name;
    }

    @Override
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(taskName + ": Step = " + i);
            try { Thread.sleep(300); }
            catch (InterruptedException e) { e.printStackTrace(); }
        }
    }
}

Running Both Threads Together

public class ThreadDemo {
    public static void main(String[] args) {

        // Thread via extending Thread class
        MyThread t1 = new MyThread("Thread-A");

        // Thread via Runnable interface
        RunnableTask task = new RunnableTask("Thread-B");
        Thread t2 = new Thread(task);

        // start() calls run() in a new thread
        t1.start();
        t2.start();
    }
}
/* Possible Output (order may vary - concurrent!):
Thread-A: Count = 1
Thread-B: Step = 1
Thread-A: Count = 2
Thread-B: Step = 2
Thread-A: Count = 3
Thread-B: Step = 3   */

       ↑____________↓ (when CPU becomes available)

Model Answer

What is an Exception?

An exception is an unwanted event or error that disrupts the normal flow of a program during execution (runtime). Examples: dividing by zero, accessing a null object, reading a file that doesn't exist, entering invalid input. If not handled, the program crashes and terminates abruptly.

Difference — Error vs Exception: Errors (like OutOfMemoryError) are serious problems in the JVM that the program cannot recover from. Exceptions are recoverable problems that can be handled gracefully using try-catch blocks.

Exception Handling Keywords

  • try: Contains code that might throw an exception.
  • catch: Handles the exception if it occurs in the try block.
  • finally: Always executes whether an exception occurred or not (for cleanup like closing files).
  • throw: Manually throws an exception object.
  • throws: Declares that a method might throw an exception.

User-Defined Exception — NegativeValueException

To create a custom exception, extend the Exception class (or RuntimeException):

// Step 1: Create custom exception class by extending Exception
class NegativeValueException extends Exception {

    public NegativeValueException(String message) {
        super(message);  // pass message to parent Exception class
    }
}

// Step 2: Class that uses the custom exception
class AgeValidator {

    static void validateAge(int age) throws NegativeValueException {
        if (age < 0) {
            // throw our custom exception
            throw new NegativeValueException("Age cannot be negative! Entered: " + age);
        }
        System.out.println("Valid age: " + age);
    }
}

// Step 3: Main class to test
public class ExceptionDemo {
    public static void main(String[] args) {

        try {
            AgeValidator.validateAge(25);   // valid
            AgeValidator.validateAge(-5);   // throws exception
        } catch (NegativeValueException e) {
            System.out.println("Exception caught: " + e.getMessage());
        } finally {
            System.out.println("Validation process complete.");
        }
    }
}

Exception caught: Age cannot be negative! Entered: -5
Validation process complete.  */

HIGH 7 Marks Every Year 2022–2025 Write a Java program to create a file sample.txt, write text to it, then read back the content. ▼

Model Answer

Java File I/O

Java provides the java.io package for reading and writing files. There are two main types of streams:

  • Byte Streams (FileInputStream / FileOutputStream): Used for binary data (images, audio).
  • Character Streams (FileReader / FileWriter / BufferedReader): Used for text data. More efficient for text.

Best practice: Use FileWriter for writing text and BufferedReader + FileReader for reading text. Always close the file after use (or use try-with-resources).

import java.io.*;

public class FileIODemo {
    public static void main(String[] args) {

        // ===== WRITE to file =====
        try {
            FileWriter writer = new FileWriter("sample.txt");
            writer.write("Java Programming is Fun!!\n");
            writer.write("File I/O in Java is easy.\n");
            writer.close();  // always close!
            System.out.println("File written successfully.");

        } catch (IOException e) {
            System.out.println("Write Error: " + e.getMessage());
        }

        // ===== READ from file =====
        System.out.println("\n--- Reading from sample.txt ---");
        try {
            BufferedReader reader = new BufferedReader(
                                         new FileReader("sample.txt"));
            String line;

            // readLine() returns null at end of file
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
            reader.close();

        } catch (IOException e) {
            System.out.println("Read Error: " + e.getMessage());
        }
    }
}
/* Output:
File written successfully.

--- Reading from sample.txt ---
Java Programming is Fun!!
File I/O in Java is easy.  */

Using try-with-resources (Modern Java)

// Automatically closes the file — no need to call close()
try (FileWriter fw = new FileWriter("sample.txt")) {
    fw.write("Hello World");
} catch (IOException e) {
    e.printStackTrace();
}

Java JDBC

Model Answer

What is JDBC?

JDBC (Java Database Connectivity) is a Java API (Application Programming Interface) that allows Java programs to connect to and interact with relational databases (like MySQL, PostgreSQL, Oracle, SQLite). It provides a standard set of classes and interfaces in the java.sql package to perform database operations: connect, query, insert, update, and delete data.

JDBC Drivers

A JDBC Driver is a software component that enables Java to communicate with a specific database. There are 4 types:

  • Type 1 — JDBC-ODBC Bridge: Converts JDBC calls to ODBC. Slow, requires ODBC installed. (Obsolete)
  • Type 2 — Native API Driver: Uses native database libraries. Platform-dependent.
  • Type 3 — Network Protocol Driver: Communicates through middleware server. Flexible.
  • Type 4 — Pure Java Driver (Thin Driver): Directly communicates with the database using Java. Most commonly used today. Example: mysql-connector-java.jar.

5 Steps to Connect Java to MySQL Database

import java.sql.*;

public class JDBCDemo {
    public static void main(String[] args) {

        // Step 1: Load the JDBC Driver
        try {
            Class.forName("com.mysql.cj.jdbc.Driver");
            System.out.println("Driver loaded successfully.");

            // Step 2: Create Connection to Database
            // URL format: jdbc:mysql://host:port/database_name
            String url  = "jdbc:mysql://localhost:3306/student_db";
            String user = "root";
            String pass = "password";

            Connection con = DriverManager.getConnection(url, user, pass);
            System.out.println("Connected to database!");

            // Step 3: Create Statement
            Statement stmt = con.createStatement();

            // Step 4: Execute SQL Query
            String sql = "SELECT id, name, semester FROM tbl_students";
            ResultSet rs = stmt.executeQuery(sql);

            // Step 5: Process Results (iterate ResultSet)
            System.out.println("ID\tNAME\t\tSEMESTER");
            System.out.println("--\t----\t\t--------");
            while (rs.next()) {
                int    id   = rs.getInt("id");
                String name = rs.getString("name");
                int    sem  = rs.getInt("semester");
                System.out.println(id + "\t" + name + "\t\t" + sem);
            }

            // Close all resources
            rs.close();
            stmt.close();
            con.close();

        } catch (ClassNotFoundException e) {
            System.out.println("Driver not found: " + e.getMessage());
        } catch (SQLException e) {
            System.out.println("SQL Error: " + e.getMessage());
        }
    }
}

Abstraction

Abstraction is the OOP concept of hiding complex implementation details and showing only the essential features or interface to the user. It is achieved in Java using abstract classes (partially abstract) and interfaces (fully abstract).

Real-world example: When you use a TV remote, you just press buttons — you don't need to know the internal electronic circuitry. The complexity is hidden; only the essential interface (buttons) is exposed.

abstract class Shape {
    abstract double area();     // abstract — no body
    void display() { System.out.println("Shape area: " + area()); }
}
class Circle extends Shape {
    double r;
    Circle(double r) { this.r = r; }
    double area() { return Math.PI * r * r; }
}

Polymorphism

Polymorphism means "many forms." It allows one method name or interface to work with different types of objects or data. In Java, polymorphism is achieved through: Method Overloading (compile-time / same class, different params) and Method Overriding (runtime / parent-child, same signature).

Real-world example: A "+" operator works for both numbers (addition) and strings (concatenation) — same operator, different behavior = polymorphism.

Thread Lifecycle in Java

A thread in Java passes through several states during its lifetime. These states are defined in the Thread.State enum.

┌─────────────────────────────────────────────────────────┐
│                   THREAD LIFECYCLE                      │
│                                                         │
│  new Thread() ──→ NEW                                   │
│                     ↓  .start()                         │
│                   RUNNABLE ←─────────────┐              │
│                     ↓ (CPU assigned)     │              │
│                   RUNNING               │ (back to      │
│                  ↙      ↘               │  queue)       │
│         BLOCKED/           DEAD         │              │
│         WAITING  ──────────────────────→┘              │
│         (sleep/wait/IO)                                 │
└─────────────────────────────────────────────────────────┘
  • NEW: Thread object created with new Thread() but .start() not yet called.
  • RUNNABLE: .start() called. Thread is ready to run, waiting for CPU time.
  • RUNNING: CPU has assigned time to this thread — run() is executing.
  • BLOCKED/WAITING: Thread is waiting for I/O, waiting for a lock, or called Thread.sleep(). Returns to Runnable when condition is met.
  • DEAD (TERMINATED): Thread has completed its run() method or was killed. Cannot be restarted.

Key methods: .start() — starts thread. .sleep(ms) — pauses for milliseconds. .join() — waits for thread to complete. .setPriority(n) — sets priority (1–10). .interrupt() — interrupts a sleeping/waiting thread.

finalize() Method in Java

The finalize() method is a special method in Java that is called by the Garbage Collector just before an object is destroyed and its memory is reclaimed. It is defined in the Object class (the parent of all Java classes) and can be overridden to perform cleanup operations.

Purpose: Used to release external resources (like file handles, database connections, network sockets) that won't be automatically cleaned up by the garbage collector before an object is destroyed.

class ResourceHolder {
    @Override
    protected void finalize() throws Throwable {
        System.out.println("Object is being destroyed. Releasing resources...");
        // close files, DB connections, etc. here
        super.finalize(); // call parent finalize
    }
}

Important Notes: finalize() is NOT guaranteed to be called — it depends on the JVM's garbage collector. It is called at most once per object. Since Java 9, finalize() has been deprecated because it causes unpredictable behavior. Modern Java uses try-with-resources and AutoCloseable interface instead for resource cleanup.
