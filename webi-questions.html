HIGH 8 Marks 2025 New Why is HTTPS more secure than HTTP? Explain HTTP request and response format in detail. ▼
Why is HTTPS considered more secure than HTTP? Explain HTTP request and response format in details.
Model Answer

HTTP vs HTTPS

HTTP (HyperText Transfer Protocol) is the foundation protocol used for communication between a web browser (client) and a web server. However, HTTP sends data as plain text, meaning anyone on the network can read or modify the data. This is a serious security risk.

HTTPS (HyperText Transfer Protocol Secure) is the secure version of HTTP. It uses SSL/TLS (Secure Sockets Layer / Transport Layer Security) to encrypt all data sent between the client and server. This means even if someone intercepts the data, they cannot read it.

Why HTTPS is More Secure

  • Encryption: All data is encrypted using SSL/TLS, so sensitive information like passwords and credit card numbers cannot be stolen.
  • Authentication: HTTPS uses digital certificates to verify that you are connected to the correct server and not a fake one (prevents man-in-the-middle attacks).
  • Data Integrity: HTTPS ensures data is not modified or corrupted during transmission.
  • Trust: Browsers show a padlock icon for HTTPS sites, showing users the connection is safe. HTTP sites are marked as "Not Secure".

HTTP Request Format

When a browser wants to communicate with a server, it sends an HTTP Request. The request has three parts:

  • Request Line: Contains the HTTP method (GET, POST, PUT, DELETE), the path (URL), and the HTTP version.
  • Request Headers: Contains additional information like Host, Content-Type, Accept, User-Agent, etc.
  • Request Body (optional): Contains data sent to the server (used in POST/PUT requests).
GET /index.html HTTP/1.1
Host: www.example.com
Accept: text/html
User-Agent: Mozilla/5.0

[ Body is empty for GET requests ]

HTTP Response Format

The server replies with an HTTP Response, which also has three parts:

  • Status Line: Contains the HTTP version, a status code (200 = OK, 404 = Not Found, 500 = Server Error), and a reason phrase.
  • Response Headers: Contains information like Content-Type, Content-Length, Date, Server, etc.
  • Response Body: Contains the actual content (HTML page, image, JSON data, etc.).
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 348
Date: Fri, 20 Mar 2026

<!DOCTYPE html>
<html>
  <body>Hello World</body>
</html>
Exam Tip: Always mention SSL/TLS encryption, the padlock icon, and give at least one example of HTTP method (GET/POST). Write the request/response format clearly with proper labels.
HIGH 8 Marks 2022 · 2025 What is a protocol? Explain different types of protocols used in the internet in detail. ▼
What is protocol? What are different protocols used in Internet? Explain any four of them in detail.
Model Answer

What is a Protocol?

A protocol is a set of rules and standards that govern how data is transmitted and received over a network. Just like humans need a common language to communicate, computers need protocols to exchange information properly. Protocols define the format, timing, sequence, and error checking of data transmission.

Different Types of Protocols Used in the Internet

1. HTTP (HyperText Transfer Protocol): HTTP is the foundation of data communication on the World Wide Web. It defines how web browsers request web pages from servers and how servers send those pages back. HTTP works on port 80. It is a stateless protocol, meaning each request is independent.

2. HTTPS (HyperText Transfer Protocol Secure): HTTPS is the secure version of HTTP. It uses SSL/TLS encryption to protect data from being read by third parties. It is used for banking, shopping, and login pages. HTTPS works on port 443.

3. FTP (File Transfer Protocol): FTP is used to transfer files between computers on a network. It allows users to upload files to a server or download files from a server. FTP uses port 21 for commands and port 20 for data transfer. It supports authentication with username and password.

4. DNS (Domain Name System): DNS is a protocol that translates human-readable domain names (like www.google.com) into IP addresses (like 142.250.80.46) that computers can understand. It works like a phone book for the internet. Without DNS, users would have to remember IP addresses instead of website names.

5. SMTP (Simple Mail Transfer Protocol): SMTP is used for sending email messages between servers. When you send an email, your email client uses SMTP to deliver the message to the mail server. SMTP works on port 25 or 587.

6. TCP/IP (Transmission Control Protocol/Internet Protocol): TCP/IP is the most fundamental protocol of the internet. TCP ensures that data packets are delivered reliably, in order, and without errors. IP is responsible for addressing and routing packets to the correct destination.

Exam Tip: If asked for "any four," choose HTTP, HTTPS, FTP, and DNS — these are the most important and easiest to explain. Always mention the port number for extra marks.
MEDIUM 7 Marks 2025 What is DNS? Explain DNS and its hierarchy. ▼
What is DNS? Explain the DNS hierarchy with a suitable diagram/example.
Model Answer

What is DNS?

DNS (Domain Name System) is a hierarchical naming system used on the internet that translates human-readable domain names into IP addresses. When you type "www.google.com" in your browser, DNS converts it to an IP address like "142.250.80.46" so the browser can find the correct server. Without DNS, users would have to remember numerical IP addresses for every website they visit.

DNS Hierarchy

DNS is organized in a tree-like hierarchical structure from top to bottom:

  • Root Level (.): This is the topmost level of the DNS hierarchy. It is represented by a dot (.). All DNS queries start from here. The root servers direct queries to the appropriate Top-Level Domain servers.
  • Top-Level Domain (TLD): These are the extensions at the end of domain names. Examples: .com (commercial), .org (organizations), .edu (education), .gov (government), .np (Nepal), .uk (United Kingdom). These are managed by ICANN.
  • Second-Level Domain (SLD): This is the unique name registered by individuals or companies. For example, in "www.google.com", the word "google" is the second-level domain.
  • Subdomain: This is an optional part added before the second-level domain. For example, "www" in "www.google.com" or "mail" in "mail.google.com".
DNS Hierarchy Example:

         . (Root)
         |
       .com (Top-Level Domain)
         |
      google (Second-Level Domain)
         |
       www (Subdomain)

Full URL: www.google.com

When a user types "www.google.com", the DNS resolution process works step by step: the browser first checks its local cache, then asks the ISP's DNS resolver, which contacts the root server, then the TLD (.com) server, then the Google DNS server, which finally returns the IP address of www.google.com.

Exam Tip: Draw or write the hierarchy clearly: Root → TLD → SLD → Subdomain. Give a real example like www.pu.edu.np to show a Nepal-based domain hierarchy.
MEDIUM 7 Marks 2021 · 2022 Differentiate between client-side and server-side scripting language with examples. ▼
Difference between client side scripting and server side scripting language. Also make a highlight on what JavaScript can and cannot do.
Model Answer

Client-Side Scripting

Client-side scripting refers to programs that run in the user's browser on their own computer. The code is downloaded from the server along with the webpage and executed locally. The server does not process the logic — the browser does.

Examples: JavaScript, HTML, CSS, VBScript

Advantages: Faster response (no server needed), reduces server load, works offline for basic tasks, provides immediate user feedback (form validation, animations).

Server-Side Scripting

Server-side scripting refers to programs that run on the web server. The user sends a request, the server processes the script, and only the final output (usually HTML) is sent back to the browser. The source code is hidden from the user.

Examples: PHP, Python (Django/Flask), Node.js, Ruby on Rails, ASP.NET

Advantages: Can access databases, handles security, can process user input safely, generates dynamic content for each user.

Comparison Table

Feature           | Client-Side        | Server-Side
------------------|--------------------|------------------
Runs on           | User's Browser     | Web Server
Speed             | Fast (no request)  | Slower (server trip)
Access to DB      | No                 | Yes
Security          | Less secure        | More secure
Example           | JavaScript         | PHP, Node.js
Source Visible    | Yes                | No

What JavaScript Can and Cannot Do

JavaScript CAN: Manipulate HTML/CSS (DOM), validate forms, respond to user events (click, hover), make AJAX requests, create animations, store data in cookies/local storage, and run in browsers without plugins.

JavaScript CANNOT: Directly access databases, read/write files on the user's computer (for security), access hardware devices directly, or run outside the browser sandbox (unless using Node.js).

HIGH 7 Marks 2021–2025 Every Year What is HTML? List out and explain different types of lists in HTML with examples. ▼
What is HTML? List out and explain different types of lists in HTML? OR: Define lists used in HTML5. Write down the three types of list with example.
Model Answer

What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure web pages. It uses "tags" (elements enclosed in angle brackets like <p>, <h1>, <div>) to tell the browser how to display content. HTML describes the structure and meaning of web content, not its appearance (that is the job of CSS). Every webpage on the internet is built using HTML.

Types of Lists in HTML

HTML provides three types of lists for organizing content:

1. Unordered List (<ul>): An unordered list displays items with bullet points. The items have no particular order or sequence. It uses the <ul> tag (unordered list) and each item is inside an <li> (list item) tag.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
Output:
• HTML
• CSS
• JavaScript

2. Ordered List (<ol>): An ordered list displays items in a numbered sequence. It is used when the order of items matters, such as step-by-step instructions. It uses the <ol> tag and items are inside <li> tags.

<ol>
  <li>Open your browser</li>
  <li>Type the URL</li>
  <li>Press Enter</li>
</ol>
Output:
1. Open your browser
2. Type the URL
3. Press Enter

3. Description List (<dl>): A description list (also called a definition list) is used to display items along with their descriptions or definitions. It uses the <dl> tag, <dt> for the term, and <dd> for the description.

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

4. Nested List: A list inside another list is called a nested list. You can place any type of list inside another list item.

<ul>
  <li>Fruits
    <ul>
      <li>Mango</li>
      <li>Banana</li>
    </ul>
  </li>
</ul>
Exam Tip: Always write all three types (ul, ol, dl) with examples. The nested list is a bonus point. Remember: <ul> = bullets, <ol> = numbers, <dl> = definitions.

What is an HTML Table?

An HTML table is used to display data in rows and columns in a structured, grid format. Tables are created using several HTML tags that work together to define the structure of the table.

Important Table Tags

  • <table>: The main container tag that defines the table.
  • <tr> (Table Row): Defines a row in the table.
  • <th> (Table Header): Defines a header cell. Text is bold and centered by default.
  • <td> (Table Data): Defines a regular data cell.
  • <thead>: Groups the header rows of the table.
  • <tbody>: Groups the body rows of the table.
  • colspan: An attribute that allows a cell to span across multiple columns.
  • rowspan: An attribute that allows a cell to span across multiple rows.
  • border: Attribute to add borders to the table.

Example: Table with Merged Cells (rowspan and colspan)

The Form Method Attribute

The method attribute of the HTML <form> tag specifies how form data is sent to the server when the form is submitted. There are two main values:

  • GET: Form data is appended to the URL as a query string (e.g., page.php?name=John&email=john@example.com). Data is visible in the URL. Used for search forms, non-sensitive data. Has a size limit.
  • POST: Form data is sent in the HTTP request body, not visible in the URL. Used for sensitive data (passwords, personal info), file uploads. No size limit.

MEDIUM 7 Marks 2025 · 2021 What is HTML? Explain HTML document structure with an appropriate example. ▼
What is HTML? Explain HTML document structure with an appropriate example.
Model Answer

What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. The term "HyperText" refers to the ability to link pages together through hyperlinks. "Markup Language" means it uses special tags to annotate (mark up) content to tell the browser how to display it. HTML is not a programming language — it is a structure language that organizes content.

HTML Document Structure

Every HTML document follows a standard structure with specific required sections:

  • <!DOCTYPE html>: Declares the document type and HTML version. It tells the browser this is an HTML5 document. It always appears at the very top.
  • <html>: The root element that wraps the entire HTML document. All other elements go inside this tag.
  • <head>: Contains metadata (information about the document) that is NOT displayed on the page. This includes the page title, links to CSS files, character encoding settings, etc.
  • <title>: Sets the title that appears in the browser tab or window title bar.
  • <body>: Contains all the visible content of the webpage — text, images, links, tables, forms, etc.
<!DOCTYPE html>          ← Document type declaration
<html lang="en">          ← Root element

<head>                   ← Metadata section
  <meta charset="UTF-8">
  <title>My Web Page</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>                   ← Visible content section
  <h1>Welcome to BCA</h1>
  <p>This is my first webpage.</p>
  <a href="https://pu.edu.np">Pokhara University</a>
</body>

</html>

CSS — Cascading Style Sheets

8 Hours · Selectors · Box Model · Flexbox · Media Queries · Responsive Design

HIGH 7 Marks Every Year 2021–2025 Define CSS. Explain different types of selectors in CSS with examples. ▼
Define CSS. Explain different types of selectors in CSS with example.
Model Answer

What is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation and appearance of HTML documents. CSS controls the color, font, size, spacing, layout, and visual effects of web page elements. It separates the content (HTML) from the presentation (CSS), making code cleaner and easier to maintain. CSS is called "cascading" because multiple style rules can apply to the same element, and they cascade down following a priority order.

Types of CSS Selectors

A CSS selector is a pattern used to select the HTML element(s) you want to style.

1. Universal Selector (*): Selects ALL elements on the page.

* { margin: 0; padding: 0; }

2. Element/Type Selector: Selects all elements of a specific HTML tag.

p { color: blue; font-size: 14px; }   /* Styles all <p> tags */
h1 { color: red; }

3. Class Selector (.): Selects elements with a specific class attribute. A class can be used on multiple elements.

.highlight { background-color: yellow; }
/* HTML: <p class="highlight">This is highlighted</p> */

4. ID Selector (#): Selects one unique element with a specific id attribute. An ID should be used only once per page.

#header { background-color: navy; color: white; }
/* HTML: <div id="header">My Header</div> */

5. Descendant Selector: Selects elements that are inside another specific element.

div p { color: green; }  /* Selects <p> inside <div> only */

6. Pseudo-class Selector: Selects elements in a specific state (like when hovered).

a:hover { color: red; }         /* Link color on mouse hover */
button:active { opacity: 0.8; } /* Button when clicked */

7. Grouping Selector: Applies the same style to multiple selectors separated by commas.

h1, h2, h3 { font-family: Arial; color: #333; }
Exam Tip: This question appears EVERY year. Always write at least 5 selectors with a code example for each. The most important ones are: element, class, ID, descendant, and pseudo-class.
HIGH 8 Marks 2021 · 2022 · 2025 What is the CSS Box Model? Explain the role of padding, border, width, and margin with examples. ▼
What is CSS box model? Explain the role of padding, border, width, and margin with examples.
Model Answer

The CSS Box Model

The CSS Box Model is a fundamental concept in web design. It defines how every HTML element is rendered as a rectangular box. This box is made up of four layers (from inside to outside):

  1. Content — The actual text or image inside the element.
  2. Padding — The space between the content and the border (inside the border).
  3. Border — A visible or invisible line surrounding the padding.
  4. Margin — The space outside the border, between this element and other elements.
┌─────────────────────────────────┐
│           MARGIN                │
│  ┌───────────────────────────┐  │
│  │         BORDER            │  │
│  │  ┌─────────────────────┐  │  │
│  │  │      PADDING        │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │    CONTENT    │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘

Box Model Properties Explained

1. Width and Height: Define the size of the content area. By default, the total element size = width + padding + border + margin.

div { width: 300px; height: 150px; }

2. Padding: The inner spacing between the content and the border. Padding is inside the element and has the same background color as the content. You can set it for all sides or individually.

p {
  padding: 20px;              /* All four sides */
  padding-top: 10px;          /* Top only */
  padding: 10px 20px;         /* Top/Bottom Left/Right */
}

3. Border: The line surrounding the padding and content. You can control its width, style, and color.

div {
  border: 2px solid black;       /* Width Style Color */
  border-radius: 10px;           /* Rounded corners */
}

4. Margin: The outer spacing outside the border. Margin creates space between two different elements. Margins are always transparent.

div {
  margin: 30px;             /* All sides */
  margin: auto;             /* Centers the element */
  margin: 10px 20px 30px 40px; /* top right bottom left */
}

Full Example

.box {
  width: 200px;
  height: 100px;
  padding: 15px;
  border: 3px solid blue;
  margin: 20px;
  background-color: lightblue;
}
/* Total width = 200 + 15+15 (padding) + 3+3 (border) = 236px */

box-sizing: border-box — A modern CSS property that makes the width include padding and border, so the total size stays at exactly the declared width. This is now the standard in web development.

Exam Tip: Always draw the box model diagram (Content → Padding → Border → Margin). This alone earns 3-4 marks. Then explain each property with a code example.
HIGH 8 Marks 2024 · 2025 Explain the role of media queries in CSS. How do they help in designing web pages for different screen sizes? ▼
Explain the role of media queries in CSS. How do media queries help in designing web pages for different screen sizes? Provide examples.
Model Answer

What is a Media Query?

A media query is a CSS technique that applies different styles to a webpage depending on the device's screen size, orientation, or resolution. Media queries are the foundation of responsive web design — websites that automatically adjust their layout and appearance to look good on any device (desktop, tablet, mobile phone).

Syntax of Media Query

@media (condition) {
  /* CSS rules applied when condition is true */
  selector { property: value; }
}

Common Media Query Breakpoints

  • Mobile phones: max-width: 576px
  • Tablets: max-width: 768px
  • Laptops: max-width: 992px
  • Desktops: max-width: 1200px

Examples

Example 1: Change background color based on screen size

/* Default style for desktop */
body { background-color: white; }

/* For tablets (768px and below) */
@media (max-width: 768px) {
  body { background-color: lightyellow; }
}

/* For mobile phones (480px and below) */
@media (max-width: 480px) {
  body { background-color: lightblue; }
}

Example 2: Responsive navigation (stack items on mobile)

/* Desktop: navigation items in a row */
nav ul { display: flex; flex-direction: row; }

/* Mobile: stack navigation items vertically */
@media (max-width: 600px) {
  nav ul { display: flex; flex-direction: column; }
  nav ul li { font-size: 14px; }
  .sidebar { display: none; } /* Hide sidebar on mobile */
}

Why Media Queries Are Important

  • More than 60% of internet traffic now comes from mobile devices, so responsive design is essential.
  • A single HTML/CSS codebase can serve all devices without separate websites.
  • Better user experience — content is readable and usable on any screen size.
  • Google gives preference to mobile-friendly websites in search rankings (SEO benefit).
HIGH 7 Marks 2022 · 2023 · 2024 Differentiate between Padding and Margin with examples. Explain CSS Properties. ▼
Differentiate between Padding and Margin with example. Explain CSS Properties.
Model Answer

Padding vs Margin — Key Differences

Padding is the space between the content of an element and its border. It is inside the element. Padding takes the background color of the element.

Margin is the space outside the border of an element. It creates space between two different elements. Margins are always transparent (no background color).

Feature      | Padding                 | Margin
-------------|-------------------------|-------------------------
Location     | Inside the border       | Outside the border
Background   | Shows element's color   | Always transparent
Purpose      | Space inside element    | Space between elements
Auto value   | Not supported           | margin: auto (centers element)
Collapsing   | Does not collapse       | Vertical margins collapse
/* Example showing difference */
.box1 {
  background-color: lightblue;
  padding: 30px;   /* Space inside - lightblue extends 30px */
  margin: 20px;    /* Space outside - transparent gap */
  border: 2px solid black;
}

CSS Properties Overview

CSS has hundreds of properties. Some of the most important ones are:

  • color: Sets the text color. Example: color: red; color: #333;
  • background-color: Sets background. Example: background-color: #fff;
  • font-size: Sets text size. Example: font-size: 16px;
  • font-family: Sets typeface. Example: font-family: Arial, sans-serif;
  • font-weight: Sets boldness. Example: font-weight: bold;
  • text-align: Aligns text. Example: text-align: center;
  • display: Controls layout. Example: display: block; flex; inline; none;
  • width/height: Sets dimensions. Example: width: 100%; height: 50px;
  • border: Adds border. Example: border: 1px solid #ccc;
  • border-radius: Rounds corners. Example: border-radius: 8px;

JavaScript Basics

8 Hours · Variables · Control Statements · Functions · DOM · Events · Form Validation

HIGH 8 Marks 2022 · 2024 · 2025 What is JavaScript? Describe its role in web development. Explain the various control statements with examples. ▼
What is JavaScript? Describe its role in web development. Also, explain the various control statements used in JavaScript with examples.
Model Answer

What is JavaScript?

JavaScript (JS) is a lightweight, interpreted, client-side scripting language that makes web pages interactive and dynamic. It was created by Brendan Eich in 1995 and is one of the three core technologies of the web alongside HTML (structure) and CSS (style). JavaScript runs directly in the browser without needing to contact the server for every action.

Role of JavaScript in Web Development

  • Interactivity: Responds to user actions like clicks, hover, key presses, and form submissions.
  • Form Validation: Validates user input before sending data to the server.
  • DOM Manipulation: Can add, remove, or change HTML elements and CSS styles dynamically.
  • Animations: Creates visual effects like sliders, popups, and transitions.
  • AJAX: Fetches data from servers without reloading the page.

Control Statements in JavaScript

Control statements determine the flow of execution of a program.

1. if-else Statement: Executes code based on a condition.

let marks = 75;
if (marks >= 90) {
  console.log("Grade A");
} else if (marks >= 80) {
  console.log("Grade B");
} else if (marks >= 60) {
  console.log("Grade C");
} else {
  console.log("Fail");
}
// Output: Grade C

2. switch Statement: Selects one of many code blocks to execute based on a value.

let day = 1;
switch(day) {
  case 1: console.log("Monday"); break;
  case 2: console.log("Tuesday"); break;
  default: console.log("Other day");
}

3. for Loop: Repeats code a fixed number of times.

for (let i = 1; i <= 5; i++) {
  console.log("Number: " + i);
}
// Prints: Number: 1, Number: 2, ... Number: 5

4. while Loop: Repeats code as long as a condition is true.

let i = 1;
while (i <= 5) {

HIGH 8 Marks 2025 New — Expected What is asynchronous programming? Explain async and fetch with an example. ▼
What is asynchronous programming? Explain async and fetch with an example.
Model Answer

What is Asynchronous Programming?

In normal (synchronous) programming, code executes line by line and the next line waits until the current one finishes. If one task takes a long time (like loading data from the internet), the entire program freezes and waits.

Asynchronous programming solves this problem. It allows certain tasks to start and then run in the background while the rest of the code continues executing. When the background task finishes, it notifies the program. This is especially important for web development, where fetching data from APIs can take time.

Promises

A Promise is a JavaScript object that represents the eventual result of an asynchronous operation. It can be in one of three states: Pending (waiting), Fulfilled (success), or Rejected (error).

async and await (ES6+)

async is a keyword placed before a function to indicate it is asynchronous. Such a function always returns a Promise. await is used inside an async function to pause execution until the Promise resolves. It makes asynchronous code look and behave like synchronous code, which is much easier to read.

fetch() API

The fetch() function is a modern built-in JavaScript method to make HTTP requests (get data from a server or API). It returns a Promise. It replaces the older XMLHttpRequest method.

// Example: Fetch data from an API using async/await

async function getUserData() {
  try {
    // fetch() sends HTTP GET request to the API
    let response = await fetch("https://api.example.com/users/1");

    // Check if the request was successful
    if (!response.ok) {
      throw new Error("HTTP Error: " + response.status);
    }

    // Parse the response as JSON
    let data = await response.json();

    // Use the data
    console.log("Name: " + data.name);
    console.log("Email: " + data.email);

  } catch (error) {
    // Handle any errors
    console.log("Error: " + error.message);
  }
}

// Call the function
getUserData();

// The rest of the code runs immediately without waiting
console.log("This runs while data is being fetched...");

How it Works Step by Step

  1. getUserData() is called — it is async, so it runs in the background.
  2. fetch() sends a request to the server and returns a Promise.
  3. await pauses getUserData() until the response arrives.
  4. response.json() converts the response to a JavaScript object.
  5. The data is used and any error is caught by try-catch.
Exam Tip: This is a new topic in the 2024 syllabus and appeared in the 2025 paper. Always mention: Sync vs Async difference, Promise states, and write the async/await fetch example with try-catch.

Model Answer

AJAX (Asynchronous JavaScript and XML)

AJAX is a web development technique that allows a webpage to communicate with a server and update parts of the page — without reloading the entire page. Despite the name, AJAX now works with JSON (not just XML) as the data format.

How AJAX Works:

  1. An event occurs in the browser (user clicks a button).
  2. JavaScript creates an HTTP request and sends it to the server.
  3. The server processes the request and sends back data.
  4. JavaScript receives the data and updates only the part of the page that needs to change.

Real-world examples of AJAX: Google search suggestions that appear as you type, Facebook "Like" button without page reload, Gmail loading new emails in the background, online shopping cart updates.

// Modern AJAX using fetch API
fetch("/api/getUser?id=1")
  .then(response => response.json())
  .then(data => {
    document.getElementById("result").innerHTML = data.name;
  })
  .catch(error => console.log(error));

Advantages: Better user experience (no page reloads), faster interaction, reduced bandwidth usage, only the changed data is transferred.

React

React (also called React.js) is an open-source JavaScript library developed by Facebook (Meta) in 2013. It is used for building fast, interactive user interfaces (UIs) for web applications. Vue.js is a progressive JavaScript framework created by Evan You in 2014. It is designed to be easy to learn and to integrate with existing projects. Vue.js is known for being lightweight, flexible, and beginner-friendly.

  • Two-way data binding (v-model): Changes in the UI automatically update the data and vice versa.

  • Component-based: Similar to React, Vue also uses reusable components.

Model Answer

DNS (Domain Name System)

DNS (Domain Name System) is often called the "phone book of the internet." It is a hierarchical system that translates human-readable domain names (like www.google.com) into machine-readable IP addresses (like 142.250.80.46) that computers use to identify each other on a network.

When you type a URL in a browser, a process called DNS resolution happens:

  1. Browser checks its local cache first.
  2. If not found, asks the ISP's DNS Resolver.
  3. Resolver contacts the Root DNS Server.
  4. Root server directs to the TLD Server (e.g., .com server).
  5. TLD server directs to the Authoritative DNS Server (e.g., Google's server).
  6. The IP address is returned to the browser.

DNS Hierarchy: Root (.) → Top-Level Domain (.com, .org, .np) → Second-Level Domain (google) → Subdomain (www)

Importance of DNS: Without DNS, users would have to memorize IP addresses for every website. DNS makes the internet user-friendly and scalable.

Typography in Web Design

Typography is the art and technique of arranging text in a visually appealing and readable way. In web design, typography involves selecting fonts, sizes, spacing, and line heights to communicate content clearly and effectively.

Key Typography Concepts:

  • Font Family: The typeface used (e.g., Arial, Times New Roman, Roboto). Serif fonts (with small strokes) are formal; Sans-serif fonts are modern and clean.
  • Font Size: The size of the text. Generally, body text is 14-16px, headings are larger.
  • Font Weight: How bold or light the text is (normal, bold, 100–900).
  • Line Height: The vertical space between lines of text. Good line-height (1.5–1.8) improves readability.
  • Letter Spacing (Tracking): Space between individual letters.
  • Text Alignment: How text is positioned — left, right, center, or justify.
  • Color Contrast: Good contrast between text and background is essential for readability and accessibility.

Why Typography Matters: Good typography makes content easier to read, establishes visual hierarchy (what to read first), creates mood and personality for a brand, and improves the overall user experience of a website.
