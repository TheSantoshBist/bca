DDL (Data Definition Language) — Commands used to define/create the structure of a database (tables, schemas). DDL does not deal with actual data.

DML (Data Manipulation Language) — Commands used to manipulate/manage actual data inside the tables.

SHORT
What is Normalization? Explain 2NF and 3NF with examples.
📌 [2+3] = 5 marks 🔥 Appeared 2082, 2081, 2079, 2079 model
▼
✅ Model Answer

Normalization is the process of organizing a database to reduce data redundancy (repetition) and improve data integrity (accuracy). It involves dividing large tables into smaller ones and defining relationships between them.

2NF (Second Normal Form):

  • A table must already be in 1NF (each cell has single value, no repeating groups).
  • Every non-key attribute must be fully functionally dependent on the entire primary key (no partial dependency).
  • Partial dependency occurs in composite primary keys: if an attribute depends on only part of the key, it violates 2NF.

Example (violates 2NF):

Order(OrderID, ProductID, ProductName, Quantity) -- ProductName depends only on ProductID (partial dependency!) -- This violates 2NF

After 2NF conversion:

Order(OrderID, ProductID, Quantity) -- primary key: OrderID+ProductID Product(ProductID, ProductName) -- separated

3NF (Third Normal Form):

  • A table must already be in 2NF.
  • There must be no transitive dependency: non-key attributes must not depend on other non-key attributes.

Example (violates 3NF):

Student(RollNo, Name, ZipCode, City) -- City depends on ZipCode (which is not the primary key) -- This is a transitive dependency!

After 3NF conversion:

Student(RollNo, Name, ZipCode) Location(ZipCode, City)
SHORT
Evaluate the advantages of DBMS compared to traditional file-based data storage.
📌 5 marks 🔥 Appeared 2081
▼
✅ Model Answer

DBMS (Database Management System) is software that manages, stores, and retrieves data efficiently. Here are 5 key advantages over traditional file-based systems:

  • Reduced Data Redundancy: DBMS stores data in a centralized location so the same data is not repeated in multiple files. File systems often store the same student info in different files.
  • Data Consistency: When data is updated in one place, it reflects everywhere. In file systems, the same data in multiple files may become inconsistent.
  • Data Security: DBMS provides access control — only authorized users can view or modify specific data. File systems have limited security.
  • Easy Data Access: Using SQL queries, data can be retrieved quickly. In file systems, complex programming is needed to search data.
  • Data Integrity: DBMS enforces rules like primary key, foreign key, and constraints to keep data accurate and valid.
  • Multi-user Access: Many users can access the database simultaneously (with concurrency control). File systems do not support this well.
  • Backup and Recovery: DBMS has built-in tools for automatic backup and data recovery in case of failure.

What is Transmission Medium? Explain its major types with advantages and disadvantages.
📌 [2+6] = 8 marks 🔥 Appeared 2082 Q15
▼
✅ Model Answer

Transmission Medium is the physical path through which data (signals) travel from one device to another in a network. It is also called communication channel or data link.

Transmission media is divided into two main types: Guided (Wired) and Unguided (Wireless).

A. Guided (Wired) Media

1. Twisted Pair Cable — Two copper wires twisted together to reduce interference.

  • Types: UTP (Unshielded) and STP (Shielded)
  • ✅ Cheap, easy to install, widely used in LAN
  • ❌ Short range, susceptible to electromagnetic interference

2. Coaxial Cable — Central copper wire surrounded by insulation, metallic shield, and outer cover.

  • ✅ Better shielding than twisted pair, good bandwidth
  • ❌ More expensive, less flexible

3. Fiber Optic Cable — Uses light pulses through glass/plastic fiber to transmit data.

  • ✅ Very high speed, immune to EMI, long distances, very secure
  • ❌ Very expensive, difficult to install and maintain

B. Unguided (Wireless) Media

1. Radio Waves — Electromagnetic waves in frequency range 3 kHz to 1 GHz. Used in AM/FM radio, mobile networks.

  • ✅ Long range, can pass through walls, easy to install
  • ❌ Susceptible to interference, security issues

2. Microwave — High-frequency waves (above 1 GHz). Used in point-to-point communication.

  • ✅ High bandwidth, no cable needed
  • ❌ Requires line-of-sight, affected by weather

3. Infrared — Short-range communication using infrared light (TV remote, IR ports).

  • ✅ No license needed, cheap
  • ❌ Very short range, cannot pass through walls

4. Satellite — Uses orbiting satellites to relay signals over large distances.

  • ✅ Global coverage, good for remote areas
  • ❌ Very expensive, signal delay (latency), weather dependent

LONG
What are the components of a function in C? Describe Call-by-Value and Call-by-Reference with examples.
📌 [4+4] = 8 marks 🔥 Appeared 2082 Q16 OR
▼
✅ Model Answer

Components of a Function in C:

  • Function Prototype (Declaration): Declares the function before it is used. int add(int a, int b);
  • Function Definition: Actual body/code of the function.
  • Function Call: Where you invoke/use the function.
  • Return Type: Data type of value returned (int, float, void).
  • Parameters: Input values passed to the function.

Call-by-Value: A copy of the argument is passed. Changes inside the function do NOT affect the original value.

// CALL BY VALUE #include <stdio.h> void change(int x) { // x is a copy x = x + 10; printf("Inside function: x = %d\n", x); } int main() { int a = 5; change(a); printf("Outside function: a = %d\n", a); // Output: Inside = 15, Outside = 5 (unchanged!) return 0; }

Call-by-Reference: The address of the variable is passed using pointers. Changes inside the function DO affect the original variable.

// CALL BY REFERENCE #include <stdio.h> void change(int *x) { // pointer receives address *x = *x + 10; // changes original value printf("Inside function: x = %d\n", *x); } int main() { int a = 5; change(&a); // pass address of a printf("Outside function: a = %d\n", a); // Output: Inside = 15, Outside = 15 (changed!) return 0; }
Call by ValueCall by Reference
Copy of data is passedAddress (pointer) is passed
Original value NOT changedOriginal value IS changed
Uses normal variablesUses pointers (*)
Safer, no side effectsEfficient for large data

#include <stdio.h> int main() { FILE *fp; int i, num; // Writing integers using putw() fp = fopen("numbers.dat", "wb"); // wb = write binary if (fp == NULL) { printf("Cannot open file!\n"); return 1; } for (i = 1; i <= 5; i++) { putw(i * 10, fp); // Writes: 10, 20, 30, 40, 50 } fclose(fp); // Reading integers using getw() fp = fopen("numbers.dat", "rb"); // rb = read binary printf("Numbers read from file:\n"); while ((num = getw(fp)) != EOF) { printf("%d\n", num); } fclose(fp); return 0; }

Always Q12 (Short Answer, 5 marks) — class, object, inheritance

SHORT
Write short notes on Class and Inheritance in OOP with examples.
📌 5 marks (2.5+2.5) 🔥 Appeared 2082, 2081, 2079 Q12
▼
✅ Model Answer

Class: A class is a blueprint or template for creating objects. It defines what data (attributes) and what behaviors (methods/functions) objects of that type will have. A class itself doesn't use memory until an object is created from it.

Object: An object is a real-world instance created from a class. It has its own values for the attributes defined in the class.

Real-world example: "Car" is a class. "Honda City with number BA-1-KH-2345" is an object.

CLASS: Animal Attributes: name, sound, legs Methods: eat(), sleep(), makeSound() OBJECT 1: Dog → name="Rex", sound="Bark", legs=4 OBJECT 2: Cat → name="Kitty", sound="Meow", legs=4

Inheritance: Inheritance is an OOP feature where a new class (child/derived class) automatically gets all the properties and methods of an existing class (parent/base class). It promotes code reusability.

  • The child class can use all features of the parent class.
  • The child class can also add its own new features.
  • Keyword used (in most languages): extends
BASE CLASS (Parent): Animal - name - eat() - sleep() ↓ (inherits all above) DERIVED CLASS (Child): Dog - name (inherited) - eat() (inherited) - sleep() (inherited) - bark() (NEW — added by Dog)

Types of Inheritance: Single, Multiple, Multilevel, Hierarchical, Hybrid.

💡 Key OOP Terms for MCQ
Encapsulation — hiding data (private members)
Polymorphism — same function, different behavior
Abstraction — hiding complexity, showing only what's needed
Inheritance — code reusability, parent-child relationship

⭐⭐⭐⭐
VERY HIGH PRIORITY
SHORT
What is Requirement Gathering? Explain different Requirement Gathering methods.
📌 [1+4] = 5 marks 🔥 Appeared 2082, 2081, 2079 Q13
▼
✅ Model Answer

Requirement Gathering (also called Requirement Elicitation) is the process of collecting, understanding, and documenting what a software system should do — what features, functions, and constraints it must have. It is the first and most important step in the SDLC analysis phase.

Methods of Requirement Gathering:

1. Interview: Direct one-on-one or group conversation with stakeholders (users, managers) to understand their needs and expectations. Can be formal (structured) or informal (unstructured).

2. Questionnaire / Survey: A written set of questions given to users to collect information. Useful when many users need to be consulted but direct interviews are not possible. Cost-effective for large groups.

3. Observation: The analyst directly watches how users currently work and what problems they face. Helps identify unstated requirements and practical issues.

4. Document Analysis: Reviewing existing documents, reports, forms, and records related to the current system. Helps understand the existing workflow and data used.

5. Brainstorming: A group meeting where participants freely suggest ideas and solutions. Used to explore many possible requirements quickly.

6. Prototyping: Building a quick, rough version (prototype) of the system to show users. Users give feedback, and requirements are refined based on it.

7. JAD (Joint Application Development): Structured workshop where users, managers, and developers work together to define requirements collaboratively.

💡 Remember for 5 marks: Name 4–5 methods with 1-line explanation each
SHORT
Write any five qualities of good software.
📌 5 marks Appeared 2079 model Q13
▼
✅ Model Answer

A good quality software should have the following characteristics:

  • Correctness: Software should perform exactly what the user requires. All functions should work correctly without bugs.
  • Reliability: Software should work consistently without failure over time. It should produce correct results every time it runs.
  • Efficiency: Software should use minimum resources (memory, processing power) while giving maximum performance.
  • Usability / User-friendly: Software should be easy to learn and use. The interface should be simple and intuitive for all users.
  • Maintainability: It should be easy to modify, update, and fix bugs in the software after it is deployed.
  • Portability: Software should work on different hardware and operating systems without major changes.
  • Scalability: Software should be able to handle increased workload (more users, more data) without losing performance.
  • Security: Software should protect data from unauthorized access and attacks.

What is AI? Explain application areas of AI in education with five examples.
📌 [1+4] = 5 marks 🔥 Appeared 2082, 2081, 2079 Q14 — EVERY YEAR!

✅ Model Answer

AI (Artificial Intelligence) is a branch of computer science that focuses on creating machines and software that can simulate human intelligence — such as learning, reasoning, problem-solving, understanding language, and making decisions.

Five Applications of AI in Education:

1. Personalized Learning: AI analyzes each student's learning style, speed, and weak areas to create customized lessons and exercises. Example: Duolingo adjusts difficulty based on student performance.

2. Intelligent Tutoring Systems (ITS): AI-powered tutors that give one-on-one guidance to students, explain concepts, and provide hints when students are stuck — like having a personal teacher available 24/7. Example: Khan Academy's AI tutor.

3. Automated Grading and Assessment: AI can automatically grade multiple-choice tests, essays, and programming assignments. It saves teachers time and provides instant feedback to students. Example: Turnitin for plagiarism checking.

4. Smart Content Creation: AI tools can generate study notes, summaries, quizzes, and educational videos from textbook content. Example: AI-generated flashcards and practice questions.

5. Early Warning Systems: AI monitors student behavior, attendance, and grades to identify students at risk of failing early, so teachers can intervene and provide extra support before it is too late.

Other examples: Virtual classrooms, Language translation tools, Chatbots for student queries, Adaptive testing.

Explain mobile computing with its advantages and disadvantages. / What is mobile computing?
📌 5 marks Appeared 2079 model Q14
▼
✅ Model Answer

Mobile Computing is a technology that allows users to access data, information, and applications from anywhere at any time using portable wireless devices such as smartphones, tablets, and laptops. It does not require a fixed location or wired connection.

Key components: Mobile Device (hardware), Mobile Communication (WiFi, 4G/5G), Mobile Software (apps, OS)

Advantages:

  • Accessibility — work from anywhere, anytime
  • Real-time communication and data access
  • Increased productivity — work while traveling
  • Location-based services (GPS, maps, navigation)
  • Cost-effective communication (WhatsApp, email)

Disadvantages:

  • Security risks — data theft, hacking on public WiFi
  • Short battery life
  • Limited screen size and processing power
  • Network dependency — poor signal = no work
  • Privacy concerns — location tracking
MCQ
Cloud Computing Services — IaaS, PaaS, SaaS (MCQ in 2082)
📌 1 mark 🔥 Appeared 2082 MCQ Q9
▼
✅ Key Facts

The three real types of cloud computing services are:

  • IaaS (Infrastructure as a Service) — Provides virtual hardware: servers, storage, networking. Example: AWS EC2, Google Cloud.
  • PaaS (Platform as a Service) — Provides platform for developers to build apps without managing hardware. Example: Google App Engine, Heroku.
  • SaaS (Software as a Service) — Provides ready-to-use software over internet. Example: Gmail, Google Docs, Microsoft 365.
⚠️ MCQ Answer
"HaaS (Hardware as a Service)" is NOT a real type of cloud computing service. The correct answer is D) HaaS in the 2082 MCQ — it is the "NOT a type" option.

  • IoT (Internet of Things) — Physical devices connected to internet (smart home, sensors)
  • Virtual Reality (VR) — Immersive simulated environment
  • Robotics — Machines that perform tasks autonomously
