Subtraction using 1's Complement and 2's Complement method with examples
7 Marks 🔥 Very Important 2021, 2024
★★★★★
▾

1's Complement Subtraction

Rule: To find 1's complement, flip all bits (0→1, 1→0).

Subtraction (A − B): Add A + (1's complement of B)

If carry occurs → Add carry to result (End-Around Carry)
If no carry → Result is negative; take 1's complement to find magnitude.

Example: 11011 − 01100 Step 1: 1's complement of 01100 = 10011 Step 2: Add 11011 +10011 ───────── 101110 ← Carry = 1 (end-around carry) Step 3: Add carry: 01110 + 1 = 01111 Answer: 11011 − 01100 = 01111 = +15 (positive since carry occurred)

2's Complement Subtraction

Rule: 2's complement = 1's complement + 1

Subtraction (A − B): Add A + (2's complement of B)

If carry occurs → Discard carry, result is positive
If no carry → Result is negative; take 2's complement to find magnitude.

Example: 11010 − 10000 (from 2024 paper) Step 1: 2's complement of 10000: 1's complement = 01111 Add 1 = 10000 ← 2's comp of 10000 is itself! Step 2: Add 11010 +10000 ──────── 101010 ← carry = 1 (discard) Answer: 01010 = +10 (positive) Verification: 26 − 16 = 10 ✓ Example 2: 1001 − 1010 Step 1: 2's comp of 1010 = 0101 + 1 = 0110 Step 2: Add 1001 +0110 ─────── 1111 ← no carry Since no carry → result is negative Magnitude = 2's comp of 1111 = 0000 + 1 = 0001 Answer: −0001 = −1 Verification: 9 − 10 = −1 ✓
📌 Key Difference: 1's complement uses end-around carry; 2's complement discards carry. 2's complement is more widely used in digital computers.

Why are Digital Systems preferred over Analog Systems? (Advantages of Digital over Analog)
7 Marks 2025 Spring, 2024 Fall
★★★★☆
▾

Definition

Analog systems use continuous signals (infinite values). Digital systems use discrete signals — only two levels: 0 (LOW) and 1 (HIGH).

Advantages of Digital System over Analog

  1. Noise Immunity: Digital signals use only 0 and 1, so small noise doesn't affect the signal. Analog signals are easily corrupted by noise.
  2. Accuracy and Precision: Digital systems can represent data with very high precision using more bits. Analog systems have limited precision.
  3. Reliability: Digital circuits are highly reliable as they operate in two states only. Aging and temperature effects are less significant.
  4. Ease of Storage: Digital data can be stored easily in memory (RAM, ROM, hard disk). Analog data storage is complex and lossy.
  5. Programmability: Digital systems can be easily programmed and reprogrammed (like computers, microcontrollers).
  6. Error Detection & Correction: Digital systems can detect and correct errors using parity bits, checksums, Hamming codes, etc.
  7. Easy to Design: Digital circuits use standard logic gates (AND, OR, NOT) which are simpler to design and implement on ICs.
  8. Lower Cost: Mass production of digital ICs has reduced costs dramatically. Digital components are cheap and widely available.
  9. Compatibility with Computers: Digital systems directly interface with computers for processing, communication, and storage.
  10. Security: Digital data can be encrypted easily for secure communication.
📌 Modern Applications: Mobile phones, computers, digital cameras, smart TVs — all use digital systems due to these advantages.

A code is weighted if each bit position is assigned a fixed positional weight. The decimal value = sum of (bit × weight).

Implement A + BC using NAND Gates

A + BC is in SOP form. For NAND-NAND implementation:

Step 1: Double complement: A + BC = ((A + BC)')' Step 2: By De Morgan: (A + BC)' = A' · (BC)' = A'(B'+C') Step 3: F = ((A)'·(BC)')' = NAND(A, NAND(B,C)) Gate connections: G1 = NAND(B, C) = (BC)' = B'+C' G2 = NAND(A, G1) = (A · G1)' = (A·(BC)')' = A' + (BC)'' = A' + BC Wait, let's be more careful: NAND-NAND for A+BC: Level 1: NAND(A,A) = A' (invert A, or just use A directly with extra inverter) NAND(B,C) = (BC)' Actually the simplest: A+BC: Level 1 (AND layer): - A alone → just A (no NAND needed for single variable) - G1 = NAND(B,C) = (BC)' Level 2 (OR layer, using NAND with inverted inputs): F = A + BC = NAND(NAND(A,A), NAND(B,C)) = NAND(A', (BC)') = (A'·(BC)')' = A'' + (BC)'' (De Morgan) = A + BC ✓

Implement A + BC using NOR Gates

Step 1: F = A + BC Step 2: Using NOR gates: G1 = NOR(B,B) = B' (inverter) G2 = NOR(C,C) = C' (inverter) G3 = NOR(G1,G2) = NOR(B',C') = (B'+C')' = B''·C'' = B·C ← AND gate using NOR G4 = NOR(A,A) = A' (inverter) G5 = NOR(G3,G3) = (BC)' (invert BC temporarily) Actually: To implement A + BC with NOR: Method: B·C = NOR(NOR(B,B), NOR(C,C)) = NOR(B',C') Then: A + BC = NOR(NOR(A, BC), NOR(A, BC)) = NOR(NOR(A, NOR(B',C')), NOR(A, NOR(B',C'))) Step-by-step: G1 = NOR(B,B) = B' G2 = NOR(C,C) = C' G3 = NOR(G1,G2) = NOR(B',C') = B·C ← implements AND G4 = NOR(A, G3) = (A + BC)' ← implements NOR G5 = NOR(G4,G4) = A + BC ✓ ← implements NOT to get final OR
💡 Memory trick: NAND-NAND = AND-OR (SOP form). NOR-NOR = OR-AND (POS form).

Universal Gate Definition

A gate is called a Universal Gate if it can be used to implement any Boolean function — i.e., if NOT, AND, and OR can all be built from it. Both NAND and NOR are universal gates.

NAND as Universal Gate

Recall: NAND(A,B) = (A·B)' = A'+B'

Implementing Basic Gates using NAND

NOR as Universal Gate

Recall: NOR(A,B) = (A+B)' = A'·B'

1. NOT gate: NOR(A,A) = (A+A)' = A' ✓ 2. OR gate: NOR(NOR(A,B), NOR(A,B)) = ((A+B)')' = A+B ✓ 3. AND gate: NOR(NOR(A,A), NOR(B,B)) = NOR(A', B') = (A'+B')' = A''·B'' = A·B ✓ Summary: NOT A = NOR(A,A) A OR B = NOR(NOR(A,B), NOR(A,B)) A AND B = NOR(NOR(A,A), NOR(B,B))
📌 Since any Boolean function can be built from NOT, AND, OR — and both NAND and NOR can implement all three — they are both called Universal Gates.

Duality Principle

The dual of a Boolean expression is obtained by:

  1. Replacing every AND (·) with OR (+)
  2. Replacing every OR (+) with AND (·)
  3. Replacing every 0 with 1 and every 1 with 0
  4. Variables are NOT complemented

The Duality Principle states: If a Boolean identity is valid, its dual is also valid.

Example: Original: A + 0 = A Dual: A · 1 = A ✓ Original: A · B = B · A Dual: A + B = B + A ✓ Original: A(B+C) = AB+AC Dual: A+(BC) = (A+B)(A+C) ✓ Function example: F = A·B + A'·C Dual of F = (A+B)·(A'+C)

Involution Law (Double Complement)

(A')' = A

Complementing a variable twice gives back the original variable.

Proof: If A=0, then A'=1, (A')'=0 = A ✓
If A=1, then A'=0, (A')'=1 = A ✓

Explain Minterm and Maxterm. What are SOP and POS forms? What is Don't Care condition?
5 Marks 2023, 2021
★★★★☆
▾

Minterm (Standard Product)

A minterm is a product (AND) of all variables in a Boolean function where each variable appears exactly once, either complemented or uncomplemented. For n variables, there are 2ⁿ minterms.

A minterm = 1 for only ONE specific combination of inputs, 0 for all others.

For 2 variables A,B: m0 = A'B' (when A=0,B=0) m1 = A'B (when A=0,B=1) m2 = AB' (when A=1,B=0) m3 = AB (when A=1,B=1)

Maxterm (Standard Sum)

A maxterm is a sum (OR) of all variables, each appearing exactly once. A maxterm = 0 for only ONE specific combination, 1 for all others.

For 2 variables A,B: M0 = A+B (= 0 only when A=0,B=0) M1 = A+B' (= 0 only when A=0,B=1) M2 = A'+B (= 0 only when A=1,B=0) M3 = A'+B' (= 0 only when A=1,B=1) Note: mᵢ = Mᵢ' (minterm and maxterm are complements)

SOP (Sum of Products)

A Boolean function expressed as a sum (OR) of product (AND) terms. Each product term contains all or some variables.

Example: F = AB + A'C + BC'

POS (Product of Sums)

A Boolean function expressed as a product (AND) of sum (OR) terms.

Example: F = (A+B)(A'+C)(B+C')

Don't Care Condition

In some problems, certain input combinations never occur (e.g., BCD codes 1010–1111 are invalid). These are called don't care conditions, denoted by 'X' or 'd'.

In K-map simplification, don't cares can be treated as 0 or 1 — whichever gives us larger groups and simpler expressions.

📌 Always use don't cares to enlarge groups in K-map for a simpler expression. Never use them as isolated 1s to create new groups unnecessarily.

A Half Adder adds two single bits (A, B) and produces Sum and Carry. It cannot handle carry input.

Full Adder Definition

A Full Adder adds three bits: two input bits (A, B) and one carry input (Cin). It produces Sum and Carry output (Cout).

What is a Flip Flop?

A flip flop (also called bistable multivibrator) is a basic sequential circuit element that can store one bit of information. It has two stable states (0 and 1) and changes state based on input signals and a clock. It is the fundamental building block of registers, counters, and memory.

State Diagram

A state diagram (also called a state graph) is a graphical representation of a sequential circuit. It consists of:

  • Circles (nodes): represent states
  • Arrows (directed arcs): represent transitions between states

Up/Down Counter Concept

An Up/Down counter can count upward (0→7) or downward (7→0) based on a control signal (M). When M=1 → count UP; when M=0 → count DOWN.

Key Idea

  • UP mode (M=1): Each FF is triggered by the Q output (normal output) of the previous FF
  • DOWN mode (M=0): Each FF is triggered by the Q̄ (complement output) of the previous FF

A 2-input MUX or AND-OR logic selects which output triggers the next FF.

Clock Input Logic

CLK for FF₁ = (M · Q₀) + (M̄ · Q̄₀)
CLK for FF₂ = (M · Q₁) + (M̄ · Q̄₁)

RAM – Random Access Memory

RAM (Random Access Memory) is a read-write volatile memory in a digital computer. "Random access" means any memory location can be accessed in the same amount of time, regardless of its address. It is volatile — data is lost when power is turned off.

Read Operation

  2. Set RD = 1 (Read enable), WR = 0

  4. Data from selected location appears on the data bus

  4. Data is stored in the selected memory location

Don't Care conditions are input combinations for which the output does not matter — either because that input combination can never occur (e.g., BCD has unused states 1010–1111) or because we simply don't care about the output.

Representation

  • Denoted by d or X or φ in truth tables and K-maps
  • Written as: F = Σm(minterms) + d(don't cares) for SOP
  • Written as: F = πM(maxterms) + d(don't cares) for POS

How to Use Don't Cares in K-map

  1. Mark don't cares as X in the K-map cells
  2. When forming groups (1s for SOP), you CAN include X cells to make a larger group
  3. When forming groups, you CAN ignore X cells if they don't help
  4. An X-only group is NOT allowed (must have at least one '1')

Example

F = Σ(0,1,4,8,10,11,12), D = Σ(2,3,6,9,15) — By treating don't cares as 1s or 0s strategically, we get larger groups and simpler expression.

📌 Don't care conditions always help reduce the complexity (or keep it same, never worse). They give us more flexibility in grouping, leading to simpler circuits with fewer gates.

Short Note: Duality Principle in Boolean Algebra
5 Marks 2024 Fall, 2023 Fall
★★★★☆
▾

The Duality Principle states that every valid Boolean expression remains valid if we make the following substitutions simultaneously:

  • Replace every AND (·) with OR (+)
  • Replace every OR (+) with AND (·)
  • Replace every 0 with 1 and every 1 with 0
  • Do NOT change the variables or complement signs

Examples of Dual Expressions

Original TheoremDual Theorem
A + 0 = AA · 1 = A
A + 1 = 1A · 0 = 0
A + A = AA · A = A
A + Ā = 1A · Ā = 0
A + (B · C) = (A+B)(A+C)A · (B+C) = AB + AC
De Morgan: (A+B)̄ = Ā · B̄De Morgan: (A·B)̄ = Ā + B̄
📌 The duality principle means Boolean theorems come in pairs. If you know one form, you can derive the dual by simple substitution. This reduces the number of theorems to memorize by half.

Minterm (Standard Product / SOP)

A minterm is a product (AND) term containing ALL n variables in complemented or uncomplemented form. A minterm = 1 for only ONE specific input combination.

  • Denoted as mᵢ (e.g., m₀, m₁, m₂...)
  • Variable is uncomplemented (A) if bit = 1, complemented (Ā) if bit = 0
  • F = Σm(...) → SOP form → "Sum of Minterms"

Maxterm (Standard Sum / POS)

A maxterm is a sum (OR) term containing ALL n variables. A maxterm = 0 for only ONE specific input combination.

  • Denoted as Mᵢ (uppercase)
  • Variable is uncomplemented (A) if bit = 0, complemented (Ā) if bit = 1 (opposite of minterm!)
  • F = πM(...) → POS form → "Product of Maxterms"

Example for 2 variables (A, B)

RowABMinterm (mᵢ)Maxterm (Mᵢ)
000m₀ = Ā·B̄M₀ = A+B
101m₁ = Ā·BM₁ = A+B̄
210m₂ = A·B̄M₂ = Ā+B
311m₃ = A·BM₃ = Ā+B̄
📌 Key relationship: mᵢ = M̄ᵢ. If F = Σm(1,3), then F = πM(0,2). The minterms where F=1 form the SOP; the maxterms where F=0 form the POS.

Short Note: Multiplexer (MUX)

A Multiplexer (MUX) is a combinational circuit that selects one of 2ⁿ input lines and routes it to a single output line based on n selection inputs. Also called a data selector.

Key Specs: 4:1 MUX

  • 4 input lines: I₀, I₁, I₂, I₃
  • 2 selection lines: S₁, S₀
  • 1 output: Y

Function Table

S₁S₀Output Y
00I₀
01I₁
10I₂
11I₃
Y = S̄₁S̄₀·I₀ + S̄₁S₀·I₁ + S₁S̄₀·I₂ + S₁S₀·I₃

Applications

  • Data routing in digital systems
  • Boolean function implementation (any function with n variables can be implemented with 2ⁿ:1 MUX)
  • Parallel to serial conversion
  • Time-division multiplexing in communication
📌 Demultiplexer (DEMUX) is the reverse: 1 input → 2ⁿ outputs. MUX and DEMUX are complementary circuits.

Boolean Algebra is a mathematical system for expressing logic. Defined by George Boole, it uses variables that can only be 0 or 1 with operations AND (·), OR (+), and NOT (¬).
