Perform Number System Conversions (Binary ↔ Octal ↔ Hex ↔ Decimal, Gray Code, BCD)
★★★★★
▼
Key Conversion Methods
① Binary → Decimal
Multiply each bit by 2position (right to left, starting from 0) and add all.
Example: (1101)₂ → Decimal = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13 Answer: (1101)₂ = (13)₁₀
② Decimal → Binary (Divide by 2)
Example: (25)₁₀ → Binary 25 ÷ 2 = 12 rem 1 12 ÷ 2 = 6 rem 0 6 ÷ 2 = 3 rem 0 3 ÷ 2 = 1 rem 1 1 ÷ 2 = 0 rem 1 Read remainders BOTTOM to TOP: 11001 Answer: (25)₁₀ = (11001)₂
③ Binary ↔ Hexadecimal
Group binary digits in sets of 4 from right → convert each group.
Example: (10111100)₂ → Hex = 1011 | 1100 = B | C Answer: (10111100)₂ = (BC)₁₆ Example: (AB)₁₆ → Binary A = 1010, B = 1011 Answer: (AB)₁₆ = (10101011)₂
④ Binary ↔ Octal
Group binary digits in sets of 3 from right → convert each group.
Example: (101110)₂ → Octal = 101 | 110 = 5 | 6 Answer: (101110)₂ = (56)₈
⑤ Binary → Gray Code
Rule: MSB stays same. Each subsequent Gray bit = XOR of current and previous binary bit.
Example: (1011)₂ → Gray Binary: 1 0 1 1 Step: ↓ ↓⊕0 ↓⊕1 ↓⊕1 Gray: 1 1 1 0 Answer: (1011)₂ = (1110)Gray Formula: G[i] = B[i] XOR B[i-1] (MSB: G[0]=B[0])
⑥ Gray Code → Binary
Example: (1110)Gray → Binary MSB: B[0] = G[0] = 1 B[1] = B[0] XOR G[1] = 1 XOR 1 = 0 B[2] = B[1] XOR G[2] = 0 XOR 1 = 1 B[3] = B[2] XOR G[3] = 1 XOR 0 = 1 Answer: (1110)Gray = (1011)₂
⑦ Decimal → BCD (8421)
Convert each decimal digit separately to 4-bit binary.
Example: (495)₁₀ → BCD 4 = 0100, 9 = 1001, 5 = 0101 Answer: (495)₁₀ = 0100 1001 0101 (BCD)
📌 Hex Digit Reference: A=10, B=11, C=12, D=13, E=14, F=15
⑧ Hex → Octal (via Binary)
Example: (AB5.9C)₁₆ → Octal Step 1: Convert to Binary A=1010, B=1011, 5=0101 . 9=1001, C=1100 Binary: 101010110101.100111000000 Step 2: Group in 3s from decimal point 101 010 110 101 . 100 111 000 000 5 2 6 5 . 4 7 0 0 Answer: (AB5.9C)₁₆ = (5265.470)₈
✅ Exam Tip: Always show each step clearly. Convert through binary when going between Octal and Hex.
7 Marks🌡 Common
Subtraction using 1's Complement and 2's Complement Method
★★★★★
▼
1's Complement Method
Steps:
  1. Find 1's complement of subtrahend (flip all bits: 0→1, 1→0)
  2. Add to minuend
  3. If carry → add carry to result (End-Around Carry)
  4. If no carry → result is negative; take 1's complement for magnitude
Example: Subtract 0110 from 1011 (i.e., 11 – 6) Minuend: 1011 1's comp of 0110: 1001 + 1001 -------- 1 0100 ← carry generated Add carry: 1 ------- Answer: 0101 = 5 ✓ (11-6=5)
2's Complement Method
Steps:
  1. Find 2's complement of subtrahend (1's complement + 1)
  2. Add to minuend
  3. If carry → discard carry; result is positive
  4. If no carry → take 2's complement of result for magnitude (result is negative)
Example: 11011 – 01010 (27 – 10) 2's complement of 01010: 1's comp = 10101 +1 = 10110 11011 + 10110 -------- 1 00001 ← discard carry Answer: 00001 = 1? Let's try: (Actually: 11011=27, 01010=10, 27-10=17=10001) Correct example: 11011 - 01110 (27-14=13) 2's comp of 01110 = 10001+1 = 10010 11011 + 10010 -------- 1 01101 → discard carry → 01101 = 13 ✓
✅ Remember: 2's complement = 1's complement + 1

7–8 Marks🌡 Common
Why are digital systems preferred over analog systems in modern communication?
★★★★★
▼
Analog vs Digital System
Analog System: Works with continuous signals that can have infinite values within a range (e.g., temperature, audio waves, voltage).
Digital System: Works with discrete signals, typically represented as 0 (LOW) and 1 (HIGH). Uses binary number system.
Advantages of Digital over Analog
  • Noise Immunity: Digital signals are less affected by noise. Even with some distortion, 0 and 1 can be correctly identified.
  • Accuracy & Precision: Digital systems can handle data with very high precision using more bits.
  • Ease of Storage: Digital data can be stored easily in memory devices (RAM, ROM, HDD).
  • Reliability: Digital circuits use transistors that are either ON or OFF — far more reliable than analog components.
  • Programmability: Digital systems can be reprogrammed easily (e.g., computers, microcontrollers).
  • Data Compression: Digital data can be compressed efficiently for storage and transmission.
  • Encryption & Security: Digital information can be encrypted easily for security.
  • Reproducibility: Copying digital data produces an exact copy with no degradation.
📌 Despite advantages, analog systems are still used where continuous signals are needed (e.g., audio amplifiers, sensors).

Show that NAND and NOR are Universal Gates. Implement basic gates using NAND only and NOR only.
★★★★★
▼
What is a Universal Gate?
A gate is called a universal gate if all three basic logic functions (NOT, AND, OR) can be implemented using only that gate. NAND and NOR are universal gates.
NAND as Universal Gate
NOT using NAND: Connect both inputs together → A NAND A = (A·A)' = A'
NOT Gate using NAND
NOT: A' = (A NAND A) AND: A·B = (A NAND B) NAND (A NAND B) = ((AB)')' = AB OR: A+B = (A NAND A) NAND (B NAND B) = A' NAND B' = (A'·B')' = A+B [De Morgan's]
NOR as Universal Gate
NOT: A' = (A NOR A) = (A+A)' = A' OR: A+B = (A NOR B) NOR (A NOR B) = ((A+B)')' = A+B AND: A·B = (A NOR A) NOR (B NOR B) = A' NOR B' = (A'+B')' = A·B [De Morgan's]
✅ Key Point: NAND is preferred in industry because NAND gates are cheaper and faster to fabricate using CMOS technology.
Implement A + BC using NAND gates
A + BC Step 1: A + BC = ((A + BC)')' = ((A'·(BC)')' [De Morgan's, double negation] = ((A NAND A) NAND (B NAND C))' ... Simpler: F = A + BC Use: F'' = ((A·(BC)')') = NAND of (A NAND all) approach Direct: BC = (B NAND C) NAND (B NAND C) A' = (A NAND A) F = A + BC = (A'·(BC)')' = A' NAND (BC)' = (A NAND A) NAND (B NAND C)

Involution Law
Double complementing a variable returns the original variable: (A')' = A. If you NOT a signal twice, you get back the original signal.
Duality Principle
Every Boolean expression remains valid if we: swap AND (·) with OR (+), and swap 0 with 1. The dual of an expression is obtained by this interchange.
Example: Original: A + 0 = A Dual: A · 1 = A ✓ Original: A + A' = 1 Dual: A · A' = 0 ✓

K-Map Rules (Must Memorize)
  • Groups must be powers of 2: 1, 2, 4, 8, 16 cells
  • Groups can wrap around (edges are connected)
  • Larger group = fewer variables in simplified expression
  • Include don't cares (X) only if they help make larger groups
  • Every 1 must be covered by at least one group
  • Use Essential Prime Implicants first (groups covering exactly one 1)

A Multiplexer (MUX) is a combinational circuit that selects ONE of many input lines and forwards it to a single output line. It acts as a data selector.

What is a Flip-Flop?
A flip-flop is a bistable sequential circuit (memory element) that can store 1 bit of information. It has two stable states: 0 and 1. Unlike combinational circuits, flip-flops depend on both current inputs AND previous state (memory).
JK Flip-Flop
The JK flip-flop is the most versatile flip-flop. It has two inputs: J (Set) and K (Reset), plus a Clock input. It eliminates the invalid state of SR flip-flop by making J=K=1 a Toggle operation.

Definition
A counter is a sequential circuit that goes through a predetermined sequence of states upon application of clock pulses. It counts in binary (or BCD, Gray, etc.).
Types: Synchronous (all FFs clocked together) vs Asynchronous/Ripple (output of one FF is clock for next).

K-Map for D inputs
D₀ (from K-map): D₀ = Q₀' (complement of Q₀) D₁ (from K-map): D₁ = Q₁ XOR Q₀ = Q₁⊕Q₀ D₂ (from K-map): D₂ = Q₂ XOR (Q₁Q₀) = Q₂⊕(Q₁·Q₀)
3-bit Counter using JK Flip-Flops
For JK: Q(t+1) = JQ' + K'Q Comparing with Q⁺ expressions: J₀ = K₀ = 1 (always toggle) J₁ = K₁ = Q₀ (toggle when Q₀=1) J₂ = K₂ = Q₁Q₀ (toggle when Q₁=Q₀=1)
✅ In synchronous counter: All flip-flops share the SAME clock. In ripple counter: Q₀ output clocks FF₁, Q₁ output clocks FF₂ — so it's slower but simpler.
📌 Mod-N Counter: A 3-bit counter counts mod-8 (0-7). For mod-6, add reset logic when count reaches 6. For mod-10 (decade counter), reset at count=10.

What is ALU?
An Arithmetic Logic Unit (ALU) is a combinational circuit that performs arithmetic operations (add, subtract) and logical operations (AND, OR, NOT, XOR) on binary numbers. It is the core computation unit of a CPU.
ALU Inputs/Outputs
  • A, B: 4-bit data inputs
  • S₀, S₁: Function select lines (choose operation)
  • M: Mode select (M=0: Arithmetic, M=1: Logic)
  • Cin: Carry input
  • F: 4-bit output
  • Cout: Carry output

Status Register (Flag Register / Condition Code Register)
A status register (also called flag register or processor status word) is a special register in the CPU that stores flag bits indicating the status of the most recent arithmetic or logical operation performed by the ALU.

RAM (Random Access Memory)
RAM is a volatile memory where any storage location can be accessed directly (randomly) in equal time regardless of its address. It consists of a grid of storage cells where each cell stores 1 bit. RAM has both read and write operations.
Basic RAM cell structure: - Address lines: select the memory location - Data lines (bidirectional): for reading/writing - Read/Write control: R/W=1 for Read, R/W=0 for Write - Chip Enable (CE): activates the memory chip

Universal Gate
★★★★★
▼
A universal gate is a gate that can implement any Boolean function without using any other gate type. Both NAND and NOR are universal gates.
Why NAND is universal: Using only NAND gates, we can implement NOT, AND, and OR:
NOT: X' = X NAND X AND: XY = (X NAND Y) NAND (X NAND Y) OR: X+Y = (X NAND X) NAND (Y NAND Y)
NAND is preferred in practice because CMOS NAND gates are simpler and faster than AND gates (require fewer transistors).
5 Marks🔥 Every Year
Don't Care Condition
★★★★★
▼
A don't care condition is a combination of input variables whose output value is unspecified because the combination never occurs in practice, or because we don't care about that output.
Don't care conditions are denoted by X or d in truth tables and K-maps.
Use in K-Map: Don't cares can be treated as either 0 or 1, whichever helps create larger groupings for simplification, leading to a simpler Boolean expression.
Example: BCD input uses only 0-9. Inputs 10-15 (1010 to 1111) never occur in BCD. So for BCD circuits, minterms 10-15 are don't cares. F = Σm(0,2,4,8) + d(10,11,12,13,14,15) Using don't cares to form larger groups → simpler F
✅ Always include don't cares in K-map groupings when they help simplify, but NEVER count them as required minterms.
5 Marks🌡 Common
Gray Code
★★★★★
▼
Gray Code is a non-weighted binary code in which only one bit changes between consecutive values (unit distance code). Also called reflected binary code.
Advantages:
  • Reduces errors in digital systems (especially in mechanical encoders)
  • Only one bit changes at a time → fewer switching errors
  • Used in K-map (columns/rows follow Gray code order)
  • Used in shaft encoders, A/D converters, error correction
Binary → Gray: G[0]=B[0], G[i]=B[i] XOR B[i-1] Gray → Binary: B[0]=G[0], B[i]=B[i-1] XOR G[i]

Duality Principle in Boolean Algebra
★★★★★
▼
The duality principle states that every Boolean expression remains valid (true) when we simultaneously:
  • Replace every AND (·) with OR (+)
  • Replace every OR (+) with AND (·)
  • Replace every 0 with 1, and every 1 with 0
  • Leave all literals (variables) unchanged
Examples of Dual pairs: A + 0 = A → A · 1 = A A + 1 = 1 → A · 0 = 0 A + A = A → A · A = A A + A' = 1 → A · A' = 0 (A+B)' = A'B' → (A·B)' = A'+B' (De Morgan's) A + AB = A → A(A+B) = A
5 Marks🌡 Common
Excess-3 Code
★★★★★
▼
Excess-3 (XS-3) code is a non-weighted, self-complementing BCD code obtained by adding 3 (0011) to each BCD digit.
Properties:
  • Self-complementing: 9's complement of any number is obtained by inverting all bits
  • Used in early digital systems for arithmetic operations
  • No pattern of 0000 or 1111 for valid digits → easy to detect errors
BCD → Excess-3: Add 0011 to BCD Example: 5 = 0101(BCD) → 0101+0011 = 1000(XS3) Example: 9 = 1001(BCD) → 1001+0011 = 1100(XS3) 1100 inverted = 0011 = XS3 for 0 → 9's complement ✓

Multiplexer
★★★★★
▼
A Multiplexer (MUX) is a combinational circuit that selects one of 2ⁿ inputs using n selection lines and routes it to a single output. It is a data selector.
4:1 MUX truth table: S₁ S₀ | Output Y 0 0 | I₀ 0 1 | I₁ 1 0 | I₂ 1 1 | I₃ Y = S₁'S₀'I₀ + S₁'S₀I₁ + S₁S₀'I₂ + S₁S₀I₃
Applications: Data routing, function generation, parallel-to-serial conversion, data transmission.
Demultiplexer (DEMUX): Opposite of MUX. Takes 1 input and routes to one of 2ⁿ outputs based on select lines.
